# Battleborn Reborn

A mod that brings Battleborn back online: story missions, operations and versus,
played together over the internet.

**Playtesting?** Start with [docs/PLAYTEST.md](docs/PLAYTEST.md). It covers what to
install, how to join the host's game, and how to send logs when something breaks.

Downloads are on the [Releases page](https://github.com/Sintax/reborn/releases).
